- **สถานะโค้ดที่ตรวจ:** branch `feature/gis-data-management` HEAD `7d0f226` (ตรวจ 7 พ.ย. 2569 แบบอ่านอย่างเดียว ไม่ได้แก้โค้ด ไม่ได้รวมงานจริง) · ปรับปรุง 8 พ.ย. 2569: เพิ่มข้อ 1.1 (ปัญหา 3 เรื่องจาก W1) และข้อ 2.1 (เลขซ้ำตาม W3) งานชิ้น 4-5 commit แล้วเป็น `fa10e1f` (8 พ.ย., ยังไม่ push)

## 1. ทำถึงขั้นไหนแล้ว

| ขั้น | สถานะ |
|---|---|
| 1. สำรวจจุดเชื่อมทั้ง 11 จุด (ข้อ 2) พร้อมหลักฐานในโค้ด | **เสร็จ** (บันทึกนี้) |
| 2. ตัดสินใจลำดับการรวม และถามหัวหน้าเรื่องที่ไม่ชัด (ข้อ 4) | รอหัวหน้า |
| 3. รวมงานจริงเข้า `main` และแก้จุดชน (งาน W3) | ยังไม่เริ่ม |
| 4. ปลดตัวล็อกที่ทำให้ GIS ใช้ได้เฉพาะเครื่องผู้พัฒนา (งาน W5-W6) | ยังไม่เริ่ม |

**ข้อสรุปหลัก**
- **รวมโค้ดเข้า `main` ได้โดยไม่ชนกับ `main`**: branch นำหน้า `origin/main` 31 commit และ `origin/main` ไม่มี commit ใหม่ที่ branch นี้ไม่มี
- **รวมแล้วระบบเดิมไม่ควรเปลี่ยนพฤติกรรม**: ระบบหลักเรียก `mount_gis(app)` อยู่แล้ว แต่ GIS ปิดอยู่โดยค่าเริ่มต้น (API ตอบ 503 `GIS_NOT_READY`, หน้าเว็บซ่อนเมนู GIS) ยังไม่ได้รันพิสูจน์บนระบบหลัก
- **แต่ "ใช้ GIS บนระบบจริง" ยังไม่ได้**: GIS ถูกล็อกให้ทำงานกับ sandbox บนเครื่องผู้พัฒนาเท่านั้น 4 ชั้น (หน้าเว็บ, runtime ฝั่ง backend, ผู้ออก token ของ Auth, เงื่อนไขใน migration) ซึ่งแผนให้แก้ใน W5-W6 และต้องผ่านการอนุมัติ
