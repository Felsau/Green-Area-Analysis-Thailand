## 3. รายละเอียดงาน

### W1. ตรวจสอบความพร้อมของฐานข้อมูล Supabase

**สิ่งที่ต้องทำ** เปิดแดชบอร์ดของโครงการบน Supabase แล้วตอบสองคำถาม

1. ฐานข้อมูลเป็น PostgreSQL รุ่น 17 ขึ้นไปหรือไม่
2. บัญชีที่ใช้งานมีสิทธิ์สร้าง role (คำสั่ง `CREATE ROLE`) หรือไม่

**เหตุผล** สคริปต์ติดตั้งฐานข้อมูล `migrations/027_gis_foundation.sql` กำหนดเงื่อนไขไว้ว่า
`server_version_num >= 170000` หากรุ่นต่ำกว่านี้ จะติดตั้งไม่ได้ทั้งชุด และแผนงานส่วนที่
เหลือทั้งหมดต้องทบทวนใหม่ ส่วนคำสั่ง `CREATE ROLE` ปรากฏอยู่ใน migration หมายเลข
027 และ 043 ถึง 047 สำหรับสร้าง `gis_owner`, `gis_worker`, `gis_native_worker`
และ `authenticator`

**ทำไมต้องเปิดแดชบอร์ด** ลองเรียกผ่าน API ด้วยคีย์ที่มีอยู่แล้ว แต่ `/rest/v1/` คืนเลข
รุ่นของ PostgREST ไม่ใช่ของ PostgreSQL และคีย์ที่มีรันคำสั่ง SQL ตรง ๆ ไม่ได้ จึงต้องดู
จากหน้าแดชบอร์ดหรือใช้รหัสฐานข้อมูลเท่านั้น

**สิ่งที่ต้องส่ง** คำตอบสองข้อ ใช่หรือไม่ใช่ พร้อมภาพหน้าจอประกอบ

**เกณฑ์ว่าเสร็จ** ทีมทราบคำตอบทั้งสองข้ออย่างชัดเจน

> **ยังไม่ต้องติดตั้ง migration และยังไม่ต้องแก้ไขฐานข้อมูลใด ๆ ในสัปดาห์นี้**

## 4. งานที่เคยอยู่ในรายการ แต่ตรวจสอบแล้วว่าไม่ต้องทำ

ก่อนส่งมอบได้ตรวจสอบซ้ำ และพบว่าสองรายการต่อไปนี้ทำเสร็จไปแล้ว จึงตัดออก

1. **บันทึกค่า digest ของ image ลงคลังโค้ด** ไฟล์ `dev/gis_local/images.lock.json`
   มีอยู่แล้ว ระบุชื่อ repository, digest, รุ่นที่ตรวจแล้ว และลิงก์ต้นทางครบทั้งสี่ตัว
   และ `dev/gis_local/manage.py` อ่านไฟล์นี้ไปใช้เอง ทดสอบแล้วว่า image ทั้งสี่ตัว
   ยังดึงจาก registry สาธารณะได้จริง
2. **สร้าง Dockerfile ของ worker** ทำให้แล้วที่
   `green-area-backend/gis_worker/Dockerfile` ทดสอบแล้วว่าภายใน image นั้น
   ชุดทดสอบ native ผ่าน **198 รายการ ไม่มีข้ามสักข้อ** รวมถึงข้อที่ตรวจว่าผลลัพธ์
   ตรงกับค่าที่ตรึงไว้ทุกไบต์ ซึ่งถูกข้ามบนเครื่องอื่นทุกเครื่อง และระบบตรวจอัตโนมัติ
   ตรวจซ้ำให้ทุกครั้งที่มีการส่งโค้ดแล้ว

---

## 5. งานที่ยังไม่ส่งมอบในรอบนี้

รายการต่อไปนี้อยู่ในแผนระยะถัดไป **กรุณายังไม่เริ่มดำเนินการ**

1. การเขียนตัวติดตั้ง migration สำหรับฐานข้อมูลบนคลาวด์
2. การย้ายที่จัดเก็บไฟล์ที่ผู้ใช้อัปโหลด

ทั้งสองรายการขึ้นอยู่กับคำตอบของงาน W1 โดยตรง จะส่งมอบในรอบถัดไป
