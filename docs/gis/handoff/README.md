# เอกสารส่งมอบงาน GIS — สัปดาห์ 9-15 พ.ย. 2569

โฟลเดอร์นี้เก็บ**ตัวสร้าง**เอกสารส่งมอบงานฉบับที่ใช้ลงนาม

เอกสารทั้งสองฉบับ **ครอบคลุมเฉพาะงานของสัปดาห์เดียว** โดยตั้งใจ งานส่วนที่เหลือ
ถูกตัดออกเพื่อไม่ให้ผู้รับมอบเริ่มงานที่คำตอบของสัปดาห์นี้อาจทำให้ต้องรื้อทำใหม่
แต่ละฉบับมีงานคนละ 2 รายการ และระบุชัดว่ายังไม่ต้องทำอะไร

| เอกสาร | ใช้ทำอะไร |
|---|---|
| `เล่าให้ฟังแบบสั้นๆ_อธิบายเพื่อน.docx` | **อ่านก่อน** อธิบายภาพรวมด้วยภาษาธรรมดา ไม่มีศัพท์เทคนิค ใช้เล่าให้ทีมฟัง ไม่ต้องกรอกอะไร |
| `เอกสารส่งมอบงาน_1_สภาพแวดล้อมที่ทำซ้ำได้.docx` | ส่งให้ผู้ดูแลเรื่องสภาพแวดล้อม · W1 ตรวจ Supabase · W2 บันทึก digest ลงรีโป · W5 สร้าง Dockerfile |
| `เอกสารส่งมอบงาน_2_สัญญาวิธีคำนวณและการอนุมัติ.docx` | ส่งให้ผู้พัฒนาบรานช์ `feature/gis-data-management` · W3 ส่ง digest · W4 สร้าง T0 ใหม่ · W6 ตรวจทาน · W7 เคาะ `legacy-v1` |

เอกสารฉบับที่ 1 และ 2 มีแบบฟอร์มให้กรอกผลและกรอบให้วางภาพหน้าจออยู่ท้ายเล่ม
ส่งเป็น `.docx` เพราะต้องกรอกกลับ ส่วน `.pdf` ไว้ให้ผู้ที่เปิด Word ไม่ได้

> **ไฟล์ `.docx` และ `.pdf` ไม่ได้อยู่ใน git** ตามนโยบายของโปรเจกต์ที่ไม่เก็บไฟล์
> binary ที่ diff ไม่ได้ (ดู `.gitignore`) สร้างขึ้นใหม่ได้ตามขั้นตอนด้านล่าง
> เมื่อสร้างเสร็จจะได้ `.pdf` สำหรับผู้ที่ไม่มี Microsoft Word ด้วย

## ต้นฉบับและการสร้างใหม่

เนื้อหาเดียวกันมีอยู่สองรูปแบบ

- `../handoff-2026-11-08-runtime.md` และ `../handoff-2026-11-08-method-and-approval.md`
  เป็นต้นฉบับที่อ่านง่ายและมีประวัติการแก้ไขใน git
- ไฟล์ `.docx` ในโฟลเดอร์นี้เป็นฉบับสำหรับลงนาม สร้างจาก `build.js`

สร้างใหม่ด้วย

```bash
cd docs/gis/handoff
npm install docx          # ครั้งแรกเท่านั้น
node build.js .
```

แปลงเป็น PDF (บน Windows ต้องเรียก soffice.exe โดยตรง)

```
"C:\Program Files\LibreOffice\program\soffice.exe" --headless --convert-to pdf --outdir . <ไฟล์.docx>
```

## หมายเหตุ

- ฟอนต์ที่ใช้คือ Leelawadee UI เพราะมีอยู่ในทุกเครื่อง Windows ทำให้เปิดที่ไหนก็เหมือนกัน
  หากต้องใช้ TH SarabunPSK ตามระเบียบ ให้เปลี่ยนค่าคงที่ `THAI` ใน `build.js` แล้วสร้างใหม่
- บล็อกคำสั่งและผลลัพธ์ใช้ฟอนต์ Consolas ซึ่งไม่มีตัวอักษรไทย `build.js`
  จึงมีตัวตรวจที่จะหยุดทำงานหากมีภาษาไทยหลุดเข้าไปในบล็อกเหล่านั้น
- ช่องชื่อผู้ส่งมอบและผู้รับมอบเว้นว่างไว้ให้กรอกเอง
- วันกำหนดส่งในเอกสารเป็นข้อเสนอ ต้องยืนยันกับหัวหน้าโครงงานก่อน
