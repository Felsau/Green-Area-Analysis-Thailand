## 3. ข้อตกลงการมอบหมายและหลักฐาน (PDF หน้า 1–2)

1. ห้ามมอบหมายงานด้วยปากเปล่าอย่างเดียว: ทุกงานลงบอร์ดพร้อม **ชื่องาน / ผู้รับผิดชอบหลัก / สิ่งที่ต้องส่ง / วันกำหนดส่ง** และระบุผู้รับงานย่อยเมื่อแบ่งงาน.
2. ประชุมทีมสัปดาห์ละครั้ง (เสนอวันจันทร์) ทำบันทึกวัน ผู้เข้าร่วม มติและงานที่มอบหมาย.
3. วันศุกร์ทุกคนส่งหลักฐานตามช่องของสัปดาห์ หัวหน้ารับตรวจและบันทึกว่าครบหรือไม่ครบ.
4. หลักฐานที่ยอมรับได้ ได้แก่ โค้ดในที่เก็บทีม ภาพหน้าจอ ไฟล์ผลทดสอบ ไฟล์เอกสาร และแบบประเมินที่ผู้ใช้กรอกแล้ว.
5. ส่งไม่ทันต้องแจ้งล่วงหน้า ระบุเหตุผลและวันส่งใหม่ในบอร์ด.
6. เก็บสำเนาแบบฟอร์มเข้าพบอาจารย์ทุกครั้ง เริ่มนับครั้งที่ 1 ตั้งแต่ 16 พ.ย. และต้องครบอย่างน้อย 8 ครั้งก่อน 8 ก.พ. 2570.
